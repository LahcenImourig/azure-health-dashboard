Azure Health Dashboard — Architecture & flux

Application hébergée sur AWS, connectée au tenant Azure, analyse par IA via Amazon Bedrock (Claude Opus 4.8).
1

Accès & authentification

L'équipe IT ouvre le dashboard en HTTPS. NextAuth gère le SSO Azure AD / Entra ID.

2

Collecte des données Azure

La couche données interroge le tenant via le Service Principal : Resource Graph, Service Health, Advisor, Cost Management, Monitor, Subscriptions.

3

Envoi à l'IA (Bedrock)

Le snapshot agrégé (token-efficient) est envoyé à Claude Opus 4.8 sur Amazon Bedrock, authentifié par le rôle IAM de l'hôte.

4

Analyse IA renvoyée

Claude renvoie un JSON validé : score de santé, brief, priorités, corrélations, clusters Advisor, anomalies de coût — affichés dans le dashboard (et chat / NL2KQL).

5

Rapport matinal automatisé

EventBridge Scheduler déclenche une Lambda à 7h → génère le rapport via l'IA → le pousse dans Microsoft Teams (Adaptive Card).

⚙

Support & sécurité

Secrets Manager stocke les secrets (SP Azure), CloudWatch assure logs/métriques, et la remédiation écrit via ARM REST uniquement si activée et autorisée.
